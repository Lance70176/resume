個人簡介

超過十年的網站開發與架構設計經驗，前期任職於 PChome、Yahoo 電商、無名小站 及旅遊新創。 最近七年專注於海外金融與遊戲產業，協助多個團隊提升網站功能與系統架構。現專精於 Laravel 架構設計與底層框架開發，自製 PHP 框架接手調整、各式功能打底與規劃、團隊成員訓練， 並同時處理線上緊急狀況。

最多曾帶領 21 位成員開發專案，後轉為精兵制度，保留 5–9 位核心成員進行開發；進入 AI 時代後，目前實際帶領 2–3 位組員， 以 「AI 數字人組長」的模式運作——熟練運用 AI 作為團隊的延伸戰力，讓小編制發揮過往大團隊的產能， 並特別注重 AI 與實際工作中各部門的權責分配與落地實作：明確界定哪些環節交給 AI、哪些由人把關， 使 AI 產出能真正銜接跨部門流程。無論是制度化的大型架構，或需精簡快速的時程安排皆為我的強項； 善於溝通、理解業務邏輯，並依公司情況在敏捷開發與瀑布式開發間切換。

在技術之外，我重視在不同領域的業務邏輯間碰撞、解決跨領域問題並身兼多角。技術設計上特別注重 資安與金流對接細節：跨系統的金流確認邏輯、出錯的確認與回復機制、活動計算方式與危機補救機制， 皆於設計初期一併納入考量——處理錯誤情境的難度往往是正常流程的三倍以上。同時熟悉台灣金流相關法規， 並評估不同金流管道的費率與優缺點，以提升專案的最終完整度。

專業專長

目前技術擅長於 PHP Laravel，可設計整套完整架構與底層框架，擅長主機集群功能拆分、Load Balance 調校、 套件與框架底層開發除錯，善於運用 Supervisor、Queue、Redis、Memcache，以及定期與秒級 Crontab 的優化。 程式設計上落實 PSR 規範與 Clean Code、多級別分層概念的實際應用；資料庫方面熟悉 DB 緩存與 SQL 調校、 正規化與反正規化的取捨，並要求 API 化的前後端分離，可協助 Web 與 App 同時進行功能邏輯接入與開發。

金流方面，為台灣金流 PChome Pi 行動錢包初版開發主力，亦有豐富的海外市場金流經驗， 接入百家以上大陸金流廠商；具台灣銀行與信用卡對接經驗，對接多家銀行不同格式與流程， 台灣三大三方金流（藍／綠／紅）皆有對接經驗。
