附錄：統計方法

交付點數：每個合入 develop 的 MR 分支算 1 個工作項；加權有效行＝新增行 ×1＋刪除行 ×0.2（仿 GitClear Diff Delta），再依檔案類型加權（業務邏輯 ×1.3、SQL／migration ×1.2、測試 ×0.6、設定／文件 ×0.3），大型 seed 資料檔降權 ×0.05，最後以 Fibonacci 映射成 1～13 點。

推估工時：commit 間隔小於 2 小時視為連續工作，每段加 1 小時起始成本（git-hours 會話法），只反映有 commit 落點的時間。

MR 統計：GitLab API 抓取 8 月建立或合併的 MR，依作者身份合併；排除 merge commit 與生成檔。
